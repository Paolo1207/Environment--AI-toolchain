# Frontend AI Engineering Assignment

**React 18 · TypeScript · Vite · Tailwind CSS · Vitest**

Assignment repository for the Frontend AI Engineering track: a production-style React frontend built with an AI-assisted workflow (Cursor / Claude Code) and documented conventions.

## Planned Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Vitest + Testing Library

## Getting Started

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
npm install
npm run dev
```

(Scripts will work once the app is scaffolded in a later assignment.)

## AI-Assisted Workflow

This project is built with Claude Code. Project conventions live in [`CLAUDE.md`](./CLAUDE.md) so the assistant follows the same rules every session.
